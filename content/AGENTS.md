# 《民国形势图》史料编写须知（分工协作用）

地图：《民国至新中国初期形势图》，1910—1954 年中国与全亚洲的交互形势图。115 个时间节点（`content/nodes.txt`，按月：`@1937.07` 表示 1937 年 7 月底的格局）。疆域不是手画的：每个节点只需说明“哪个归属点（城市、城镇、辅助点）此刻归哪个单位”，程序据此沿山川与国界自动推算疆域。你的工作是把某一时段或某一地区的史料写成下面几种文件。**只写你自己分工的文件，不要改别人的文件。** 写完运行 `python3 tools/check.py --part <你的文件名关键字>`，必须零错误。

## 总体要求

- **史实准确第一。** 不确定的日期、归属、地望，先查（可上网搜索），查不到就不写或写得粗一些，宁缺毋滥。日期一律用公历（1912 年起民国用公历；1911 年的事件也写公历月份）。
- **文字风格“史地札记”**：短、具体、有出处感，每条只讲这个地方/这件事为什么重要。
- **立场与用语：采用中华人民共和国通行的史学表述（统编教材口径）**，以统编历史教材、《中国共产党历史》、《中国人民解放军战史》、《中国抗日战争史》的用语为准。**只改措辞与评价，不改史实**：日期、地点、胜负、兵力伤亡照旧；数字取中方权威统计，与他方差别很大的注明“据中方统计”。不用“蒋匪”“日寇”“共匪”一类贬称，也不评价人物功过（概述里可以有教材式的定性，一节点至多一句）。
  - **时代与纪年**：1912—1949 称中华民国、北洋政府、南京国民政府（国民政府、国民党政府）；1949 年 10 月起称中华人民共和国、新中国，只用公元，不用民国纪年；国民党退台后称“台湾当局”“国民党当局”，不称“中华民国政府”。
  - **国共关系与解放战争**：第一次国共合作、国民大革命；四一二反革命政变、七一五“分共”；南昌起义、秋收起义、广州起义；“围剿”与反“围剿”加引号；红军长征；西安事变和平解决；皖南事变（国民党顽固派制造）；1946 年国民党发动全面内战；人民解放军“解放”某地，国民党军“起义”“投诚”“被歼”；辽沈、淮海、平津三大战役；渡江战役；国民党当局退踞台湾。“国军”一律改为“国民党军”（抗战期间可称“国民党军队”“中国军队”）；“易手”“攻占”在解放战争语境里改为“解放”“占领”“失守”等相应说法。
  - **抗日战争**：中国人民抗日战争（1931—1945）；九一八事变、七七事变（卢沟桥事变）、全民族抗战；侵华日军、日本侵略者、日军；沦陷、收复、光复；正面战场、敌后战场、抗日根据地；伪政权一律冠“伪”（伪满洲国、汪伪国民政府、伪华北临时政府、伪维新政府、伪蒙疆联合自治政府、伪冀东防共自治政府）、伪军；南京大屠杀遇难同胞 30 万以上；日本无条件投降；台湾光复。
  - **边疆**：外蒙古 1911、1921 年的“独立”加引号，写明沙俄、苏俄策动，1945 年公民投票、1946 年国民政府承认其独立；西藏 1912—1913 年“驱汉”、西姆拉会议、非法的“麦克马洪线”、1949 年“驱汉事件”、1950 年昌都战役、1951 年和平解放西藏（十七条协议）；新疆 1933 年所谓“东突厥斯坦伊斯兰共和国”为分裂政权（加引号），1944—1949 年伊犁、塔城、阿山三区的革命称“三区革命”，是中国新民主主义革命的一部分，1949 年新疆和平解放；1951 年印度非法侵占达旺。
  - **朝鲜战争**：中方称抗美援朝战争；朝鲜内战爆发后美国武装干涉，并派第七舰队侵入台湾海峡；中国人民志愿军、朝鲜人民军；以美国为首的“联合国军”（加引号）；第一至第五次战役、上甘岭战役、金城战役；1953 年 7 月 27 日签订停战协定，抗美援朝战争胜利。
  - **其他**：越南人民抗法战争、奠边府战役（越南人民军大捷）、日内瓦会议恢复印度支那和平；叙列强侵华时可适度用“帝国主义”（沙俄、日本帝国主义、英帝国主义）。
  - **胜负 `sides`** 格式不变，用中方称谓：“中国工农红军 胜 国民党军”“八路军 胜 日军”“中国人民志愿军·朝鲜人民军 胜 “联合国军””。
- 今地写“省 + 市县 [+ 区、镇]”，省、市二字省略，如“江西瑞金”“河北涿州”“山东枣庄台儿庄区”。外国写“国名 + 城市”，如“缅甸密支那”“马来西亚吉隆坡”。
- 经纬度保留两位小数，取今日城市或遗址位置。

## 1. 归属点 `content/seeds/<分工>.txt`（地区分工才需要）

`ID 经度 纬度 今地 [类型] [N=年.月:名,年.月:名] [R=倍数]`，一行一个；今地里不能有空格。

- 类型：`z` 城市（默认，界面上有空心圆和归属沿革）、`c` 城镇（小点）、`r` 辅助点（不显示，只参与分区，用来填满荒漠、山区、草原，免得被远处的点占去）。
- `N=` 名称沿革，如 `N=1910:京城,1945.8:汉城`；`R=` 可达代价倍数，人烟稀少的大片地区设 1.4—2。
- ID 全图唯一（中国部分已在 `seeds/cn.txt`，约 690 个，不要重复）。重名加后缀：`安东·朝鲜`，界面只显示“·”前的部分。
- 密度：政治上有变化的地方要密（战线、占领区、殖民地分区边界两侧），平稳的大片地区可以稀，但每块可能单独着色的地区都要有点，否则会被邻居吞并。

## 2. 单位 `content/units/<分工>.py`

政权（state）、部族或无主地带（tribe）、二级单位（zhen：派系、根据地、殖民地分区、占领区）。写法见 `units/_h.py`，核心单位在 `units/core.py`，可直接用，不要重复定义：

```python
from _h import mk
U = []; S, T, Z = mk(U)
S("暹罗", "暹罗", "说明……")            # 政权
Z("东京", "东京（北圻）", "法国", "说明……")  # 二级单位，默认属法国
```

单位说明：政权约 100—200 字，可分行（`\n`）写：都城 / 政体 / 关键人物 / 与本图时段相关的大事。二级单位约 40—100 字。`core.py` 里说明留空的单位，由分工表里指定的人写在 `content/notes/<分工>.json`：`{"单位键": "说明"}`。

## 3. 各节点归属 `content/snaps/<分工>.txt`

```
# 注释
@1937.07
中央{南京}: 南京 上海 杭州 …            # 单位键{治所}: 归属点……（本节点起这些点归它）
晋系[晋系（阎锡山）]>国民政府: 太原 大同   # [显示名] 本节点起的地图名称；>政权 本节点起的所属政权
冀察: @冀察                                # @单位：本节点开始时该单位的全部点
日占区: 北京 天津 宛平
·: 某点                                    # 无主
+斜线: 冀察 伪满洲国                        # 加斜线（名义归属与实际控制不一致）
-斜线: 冀察
```

- 每个节点**继承上一节点**，只写变化。你负责的文件里，**第一个节点块必须把你负责的全部归属点逐个写一遍**（时段分工的从你的第一个节点写起，地区分工的从 `@1910.08` 写起），之后只写变化。中国时段分工（cn1—cn7）的第一个节点块第一行写 `!重置`：清空上一时段留下的显示名、所属政权、治所与斜线，然后把本节点各单位的显示名、所属、治所、斜线都重新写明。第一个节点块里不要用 `@单位` 引用。
- `[显示名]`、`>所属政权`、`{治所}` 会一直保留到再次改写；`[]` 清除显示名。治所是一个归属点 ID，地图上画双环。
- 一个单位跨着两种身份时用 `>` 改所属，例如 1926.07 冯玉祥部 `国民军[西北军]>国民政府:`；1928 年后名义服从南京的地方实力派写 `>国民政府` 并 `+斜线`。
- 斜线的含义（本图统一）：名义归属与实际控制不一致——日本扶植的傀儡政权；名义服从中央、实际自立的地方实力派；受保护国、委任统治地；中华民国主张主权而未能实际管辖的西藏、外蒙古（外蒙古至 1946.01 中华民国承认其独立）；1937—1945 名义属国民政府、实由中共掌握的边区与根据地。
- 只改你负责的归属点和单位；`[显示名]`、`>所属`、斜线只动你负责的单位。核心政权的显示名归属：中国各政权、派系归中国时段分工；日本、俄国、美国归东北亚分工；英、法、荷、葡、德及其殖民地归东南亚、南亚西亚分工各自的部分。

## 4. 概述 `content/desc/<分工>.txt`（中国时段分工写）

`@1937.07 | 概述` 一节点一行，约 120—180 字：先中国（各方格局与存亡、本期大事），再用一两句交代同期亚洲的大事（日本、朝鲜、苏俄、东南亚、印度、西亚）。
