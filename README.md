# 民国至新中国初期形势图

[![中文](https://img.shields.io/badge/lang-%E4%B8%AD%E6%96%87-red.svg)](README.md) [![English](https://img.shields.io/badge/lang-English-blue.svg)](README.en.md)

辛亥革命至抗美援朝胜利、日内瓦会议（1911—1954，以 1910 年清末开篇）的中国与全亚洲交互历史地图，中英双语：115 个按月的时间节点，从清末、北洋军阀统治与军阀混战，到中国共产党成立、第一次国共合作与北伐、中原大战，南昌起义、秋收起义、各地革命根据地与红军长征，再到日本侵华与全民族抗战、太平洋战争、解放战争与中华人民共和国成立、抗美援朝战争与越南人民抗法战争，止于 1954 年的日内瓦会议。视野包括全亚洲：日本扩张、朝鲜、西伯利亚、印度支那、东南亚、南亚、中亚与西亚的变化都在图上。

图上有 319 个政权、派系、根据地与殖民地分区，1467 处城市城镇的归属沿革，471 场战役、499 件事件、82 条行军路线（长征四路与西路军、抗美援朝、进军西藏、越南抗法战争逐站标出到达日期），134 处都城驻地、84 条铁路、49 处租界与租借地、33 处关隘。

## 一、直接看

双击 **`docs/index.html`**，用任意现代浏览器（Chrome、Edge、Safari、Firefox）打开即可。

这个文件约 12 MB，数据、样式、脚本全部内嵌：不联网、不需要服务器、不依赖任何外部库。可以直接拷到 U 盘、发给别人，或者放到自己的网站上。

- **时间轴**：每年至少一个节点，辛亥、北伐、长征、1937、1941—1942、1945、1948—1949 等年份按月拆成多期（如长征：1934.10 出发、1934.12 湘江、1935.01 遵义……1935.10 吴起镇）。点刻度跳转，左侧 ▶ 播放，下方 1× / 2× 切换倍速；键盘 ← → 逐节点。
- **着色**：顶栏「派系 / 政权」切换。「派系」模式下北洋各系、地方实力派、国民政府中央、中共各苏区与根据地、日本各殖民地与占领区、英法荷美各属地分别着色；「政权」模式下并入所属政权。颜色按派系分色带，色带之间不重叠：国民党一脉为蓝（辛亥各省军政府为浅蓝），共产党各苏区、根据地、解放区与新中国各大区同为红色、以深浅区分，日本及其殖民地、占领区为深紫，伪政权为浅紫，清与北洋中央为黄，其余地方实力派与外国只用土黄、橄榄、绿、青绿，彩度较低。
- **叙事口径**：采用中华人民共和国通行的史学表述（统编历史教材口径），1949 年 10 月以后只用公元纪年；只改措辞与评价，不改史实。
- **斜线**：名义归属与实际控制不一致——日本扶植的傀儡政权（伪满、冀东、蒙疆、华北临时政府、汪伪等），1928 年后名义服从南京、实际自立的地方实力派，西藏与外蒙古，受保护国与委任统治地，以及 1937—1945 年名义属国民政府、实由中共掌握的边区与根据地。
- **行军路线**：本期走过的一段画实线加箭头，此前走过的画虚线。长征、北伐、日军攻势、远征军、美军跳岛、苏军出兵东北、三大战役后的进军、朝鲜战争都有。
- **专属图层**：铁路（按通车与拆毁时间显示）、公路与驼峰航线、租界与租借地（按设立与收回时间显示）、黄泛区（1938—1947 黄河改道）。
- **视野**：顶栏下拉框有中国、亚洲全图、长征沿线与 20 个地区（含朝鲜战场、印度支那）。
- **语言**：地图右上角「中 | EN」切换（年表、对照表视图里在内容区右上角），选择会记在浏览器里；网址末尾加 `#en` 直接打开英文版。英文界面里地图只标英文，悬停说明、索引、年表、对照表在英文名后附注汉字原名；检索中英文都可以，英文不必打变音符号。

## 三、本地构建

改了史料内容（`content/`）或参数（`src/config.py`）之后才需要重新构建。需要 **Python 3.10 或更新版本**，内存 6 GB 以上。

**macOS / Linux**

```bash
cd minguo-xinzhongguo-map
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py --open
```

**Windows（PowerShell）**

```powershell
cd minguo-xinzhongguo-map
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py --open
```

完整构建约 15—20 分钟（栅格 359 万格、115 个节点），完成后用浏览器打开新生成的 `docs/index.html`。

| 命令 | 作用 |
|---|---|
| `python run.py` | 检查史料 → 底图缺失则下载 → 计算疆域 → 拼装 HTML |
| `python run.py --html` | 只重新拼装 HTML（只改了 `src/template.html` 或 `content/en/` 时用，几秒钟） |
| `python run.py --html --draft` | 英文有缺译或过期时也照常生成（缺译处临时显示中文）；不加 `--draft` 时会报错停下 |
| `python tools/i18n.py status` | 英文版状态：缺译、过期、未登记指纹各多少条（详见第七节） |
| `python run.py --open` | 构建完后在浏览器中打开 |
| `python tools/check.py` | 只检查史料格式与引用（几秒钟）；`--node 1937.12` 列出某节点各单位领有的点，`--who 中共` 列出某单位在各节点领有多少点 |
| `python run.py --preview 1937.12,1944.12` | 额外画出这几个节点的疆域草图到 `build/preview-*.png` |
| `python tools/preview.py 1935.06 --box 99,118,24,39 --mode zhen` | 只画草图，可指定经纬框（西,东,南,北） |
| `python tools/screenshot.py` | （可选，需 playwright）走一遍全部节点并截图，检查脚本错误 |
| `python tools/stats.py` | 统计节点、条目、归属点、单位数量 |
| `python tools/verify.py` | 逐节点核对每个归属点是否落在所属单位的疆域里，列出偏出 3 km 以上的点 |

压缩包里已经带了底图数据（`geodata/`，约 43 MB），离线也能构建；删掉后 `run.py` 会自动从 GitHub 下载固定版本（ETOPO 地形另做 sha256 校验）。

同一环境下，同一份输入的构建结果逐字节一致，可以放心用 git 追踪改动。

构建完成后，把 `docs/index.html` 一起提交并推送到 `main`，线上网页会自动更新。

## 五、工作原理

```
content/ ──────┐
               ├─► build.py ─► build/geo.json + data.json ─► assemble.py ─► docs/index.html
geodata/ ──────┘                                               ▲
                                                 src/template.html
```

### 1. 为什么疆域要“算”出来

能确定的是“某月某城归谁”，很少有连续的边界线。所以这里只手写**点 → 单位 → 政权**的归属（`content/snaps/`），再用一张“通行代价”地图让计算机推出点与点之间的分界，让分界尽量落在山脊和大河上。

本图用“混合做法”：近代的国界与殖民地界精确可考，单靠推算会画偏（如中缅、中印、印度支那各界），所以把今国界（剔除近代未定或晚出的几段）连同手画的历史界线（三八线、库页岛北纬 50° 线、关东州北界等）烧成代价极高的“国界墙”，推算出的分界就会贴着这些界线走。墙可以有时效：三八线只用到朝鲜战争爆发前，战时战线完全由归属点决定，1953 年 7 月起换成军事分界线，1954 年 7 月起加越南北纬 17 度线；中国境内的派系、根据地、占领区与战线仍完全由归属点推算，今省界只作一道弱墙。贴着国界的城镇（如希瓦、新义州）周围不烧墙，免得本城被墙带围住、格子反被远处的点占去。

### 2. `build.py` 的步骤

1. **读史料**：`src/content.py` 读入并校验全部 `content/` 文件。时间一律换算成月序（年 × 12 + 月 − 1）。
2. **解析时间节点**：`snaps/*.txt` 是一个小型声明式语言（语法见下文）。每个 `@年.月` 块继承上一节点的全部归属，只写变化的部分；中国各时段文件的第一块以 `!重置` 开头并写全全部中国归属点。
3. **投影平面栅格**：先投影（Albers 等积圆锥，标准纬线 25°N、47°N，原点 32°N、103°E），再在投影平面上切等距格子（边长约 7.3 km），范围为 26°E—180°E、11°S—72°N 去掉乌拉尔—里海—高加索以北的欧洲、博斯普鲁斯以西与红海以西。面积 0.15 平方度以上的湖当作水面。
4. **代价栅格**：每格基础代价 1，加上 ETOPO20 地形起伏与 2500 米以上的高原、`geo.RANGES` 的山脉脊线、Natural Earth 山地多边形、界河（长江、黄河、淮河、怒江、鸭绿江、黑龙江、湄公河、印度河、幼发拉底河……）、国界墙与省界弱墙，最后乘 ±38% 的多尺度平滑噪声。
5. **多源最短路**：所有归属点作为源，在 16 邻接陆地网格上跑一次 `scipy.sparse.csgraph.dijkstra(min_only=True)`，每格归代价距离最近的点。超出可达代价的格子为无主地；外缘闭运算、平滑，再叠一层平滑位移场（国界墙与界河两侧渐减为 0）。
6. **出多边形**：逐节点按归属分区，在相邻两类平滑值相等处描出共享界线，三轮拉普拉斯平滑，`polygonize` 拼成覆盖图后 `coverage_simplify` 整体简化。相邻节点没变的几何只存一份（`GEO.pool`）。
7. **配色**：每个单位先归入一个派系色带（`BANDS`）：国民党一脉蓝、辛亥军政府浅蓝、共产党红、日本深紫、伪政权浅紫、清与北洋黄，其余土黄—橄榄—绿—青绿；归带按 `BAND_UNITS` 指定，或按所属政权自动判断（只属中共的进红带，只属日本与伪政权的进紫带）。色带内再按全部节点的邻接关系贪心着色，相邻两块尽量拉开深浅；英法荷美各属地靠近宗主国的颜色。个别政权用 `PRESET_COLORS` 固定。
8. **底图与条目**：海岸、今国界、湖泊、荒漠来自 Natural Earth，东端跨过国际日期变更线（含夏威夷、中途岛）。黄河 1938.06—1947.03 花园口决口改道，图上这段时间不画今黄河下游，改画黄泛区。

### 3. 前端（`src/template.html`）

- **零依赖**：原生 JavaScript + SVG。
- **时间**：每个节点涵盖“上一节点之后至本节点”的月份。战役、事件、行军路线只显示本期的；在索引、年表里点其他时期的条目，时间轴自动跳过去。铁路、租界按起止年月显示。
- **都城**：只显示当期都城（实心框）和已经做过都城的旧都（虚线框）。
- **语言**：全部文字按当前语言取值（`LZ(中, 英)` 与 `iF(条目, 字段)` 等几个取值函数），切换时重绘地图、索引、年表与对照表。英文注记用画布实测宽度参与避让，疆域里放不下的长名自动折成两行。
- **主题**：颜色全部是 CSS 变量，跟随系统深浅色；每个单位的颜色是 `--u-<序号>`，由 `assemble.py` 注入。

## 六、常见修改

**改某地某月的归属**：在对应时段的 `snaps/*.txt` 对应节点块里加一行，例如 1938 年 10 月把岳阳划给日军占领区：

```
@1938.10
日占区: 岳阳
```

**新增一个点**：在 `seeds/` 对应地区文件加一行 `ID 经度 纬度 今地 [类型] [N=年.月:名,…]`，再在每个时段文件的第一个节点块里把它分给某个单位（`python tools/check.py` 会列出漏分的点）。

**地名改名**：在该点加 `N=1910:旧名,年.月:新名`，如 `N=1910:奉天,1929.4:沈阳,1932.3:奉天,1945.8:沈阳`。

**新增时间节点**：在 `nodes.txt` 插入 `@年.月 | 纪年 | 标题`，在 `desc/` 写概述，再在需要的 `snaps/*.txt` 里写出这个月相对上一节点的变化。

**加战役、事件、都城、关隘、租界、铁路**：在 `items/` 对应文件照格式加一条，日期写 `"1937.08.13"` 或 `"1937.08"`。战役和事件按日期自动归入对应节点。

**加行军路线**：在 `items/routes.py` 加一条，`pts` 每点写 `[经度, 纬度, "到达日期", 地名]`。

**加政权、派系、根据地**：在 `units/` 用 `S(...)`（政权）、`Z(...)`（派系等二级单位）、`T(...)`（部族、无主地带）加一条，再在 `snaps/` 里使用它的键。

**边界不该翻过某座山**：在 `geo.py` 的 `RANGES` 里加这条山的脊线坐标，最后一位设为 `1`（主干，代价更高）。

**只改页面样式或交互**：编辑 `src/template.html`，然后 `python run.py --html`。

**新增或改动了任何中文**（点、条目、单位、节点说明……）：同时补写或改写 `content/en/` 里的英文，否则严格构建会报缺译或过期，见第七节。

### `snaps/*.txt` 语法速查

```
@1937.07                                        开始一个节点（继承上一节点）
!重置                                           清空本组文件（cn1—cn7 为一组）单位的显示名、所属、治所与斜线
单位: 点 点 点                                  把这些点划给单位
单位[显示名]{治所}>所属政权: 点 ……              同时设定显示名、治所、隶属（都可省略）
单位[]:                                         清除显示名，恢复 units 里的名字
单位: @另一单位                                  把“本节点开始时”属于另一单位的点全部划过来
·: 点 点                                        设为无主
+斜线: 单位 单位 / -斜线: 单位                    加上或去掉斜线（名实不符）
# 注释
```

显示名、治所、隶属、斜线一经设定会延续到后面的节点，直到再次改写或 `!重置`。

## 七、英文版

中文是源文本，英文按同样的键写在 `content/en/` 里；有了这个目录，`assemble.py` 会打开地图右上角的「中 | EN」切换（网址末尾加 `#en` 直接打开英文）。

| 文件 | 内容 | 键 |
|---|---|---|
| `units.json` | 政权、派系、根据地、殖民地分区：全称 `n`、地图短名 `s`、说明 `note` | 单位键 |
| `labels.json` | 节点里的当年别名 | 中文别名 |
| `seeds.json` | 城市城镇：今地 `mod`、各时期名称 `n` | 点的 ID |
| `items.json` | 条目各字段 `old` `mod` `note` `yt` `sides` `cmd`，路线途经地名 `p` | `类别:名称`（都城另加 `@政权键`） |
| `snaps.json` | 节点：纪年 `era`、标题 `t`、概述 `d` | `年.月` |
| `misc.json` | 海名、今省名 | 中文名 |

`zh.lock.json` 记着每条英文写成时对应中文的指纹（sha1 前 10 位）。中文改了而英文没改，构建就报“过期”。译名与写法的规矩见 `content/en/GLOSSARY.md`（拼音与少数民族地区地名、外国地名、立场用语、纪年与日期、战役胜负的写法等）。

改了中文以后：

1. `python tools/i18n.py status` 看缺译、过期各多少条；
2. `python tools/i18n.py todo` 列出这些条目的中文，到对应 JSON 里补写或改写英文；
3. `python tools/i18n.py lock` 登记新的中文指纹；
4. `python run.py --html` 重新拼装。`python tools/i18n.py table` 可导出中英对照表供审校（`table names` 只导出名称）。

英文先译名称、经作者审定，再译按语、节点概述与政权说明；两轮都经独立核查，核查中发现的中文史实与今地问题先改中文、再改英文。

## 九、资料与可靠程度

- **底图**：[Natural Earth](https://www.naturalearthdata.com/) 1:10m 矢量数据（公有领域），固定在提交 `ca96624`；ETOPO20 地形取自 matplotlib basemap v1.4.1 示例数据。
- **今省界**：沿用《唐宋之际形势图》的简化省界。
- **史料**：中国部分据各时期官方文书、战史与通行近代史著作，清末部分参照谭其骧《中国历史地图集》第八册（清时期）大意；亚洲各地据通行史地图集与各国通史大意。全部条目经过一轮独立核查。
- **局限**：
  - 疆域边界是由城市、县城的归属推算的示意线，不是考证出的历史界线。
  - 抗战与内战时期的战线犬牙交错，日军多只控制城市与交通线，根据地与游击区在乡村；图上以县城的控制为单位，只能画出“点线”格局的大意。
  - 军阀割据时期各派防区变动频繁，一个节点只取所标月份之末的格局。
  - 西伯利亚、青藏、阿拉伯半岛、新几内亚等地归属点稀疏，边界尤其粗略。
  - 日期一律为公历。
  - 英文据中文翻译，立场用语照中华人民共和国官方英文，译名体例见 `content/en/GLOSSARY.md`。
